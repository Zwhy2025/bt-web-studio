# 术语表

## 基础术语

| 术语 | 说明 |
|---|---|
| BehaviorTree.CPP | C++ 行为树库，项目 XML 与调试协议的主要兼容目标 |
| Groot / Groot2 | 行为树可视化与调试工具，项目协议设计的重要参考 |
| Composer Mode | 编排模式，负责结构编辑 |
| Debug Mode | 调试模式，负责在线执行观察与控制 |
| Replay Mode | 回放模式，负责离线复盘 |
| Blackboard | 行为树运行时共享变量空间 |
| Hook | 协议层钩子机制，含断点等控制能力 |
| Timeline | 回放时间轴，表示事件序列 |
| Slice | Zustand 状态切片 |

## 协议术语

| 术语 | 说明 |
|---|---|
| REQ/REP | ZeroMQ 请求-响应模型 |
| PUB/SUB | ZeroMQ 发布-订阅模型 |
| `unique_id` | 请求唯一标识，用于匹配响应 |
| `tree_id` | 当前行为树 UUID |

## 代码约定术语

| 术语 | 说明 |
|---|---|
| 结构层 | `nodes` / `edges` 等静态树结构 |
| 运行态 | 节点状态、执行事件、黑板快照 |
| 合成状态 | 回放时根据时间点投影出的节点状态 |
