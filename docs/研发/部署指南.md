# 部署指南

## 1. 目标与范围

- 目标：提供本地与容器化部署路径。
- 范围：前端构建、Docker、Compose、调试代理启动建议。

## 2. 本地部署

1. 安装依赖：`npm install`
2. 生产构建：`npm run build`
3. 本地预览：`npm run preview`

默认预览地址由 Vite 输出信息决定（通常为 `http://localhost:4173`）。

## 3. Docker 部署

1. 构建镜像：`npm run docker:build`
2. 运行容器：`npm run docker:run`

## 4. Compose 部署

1. 启动：`npm run compose:up`
2. 停止：`npm run compose:down`

## 5. 调试代理（可选）

若需要接入 Groot2/ZMQ 后端，启动 Python 代理：

1. 安装依赖：`pip install -r scripts/requirements.txt`
2. 启动代理：

```bash
python scripts/proxy.py --bt-ip localhost --req-port 1667 --pub-port 1668 --host localhost --ws-port 8080
```

## 6. 验证建议

- 前端校验：`npm run lint`、`npm run build`
- 代理联调：`python tests/proxy_batch_test.py --ws ws://localhost:8080`
- ZMQ 联调：`python tests/zmq_batch_test.py`
