# BT Web Studio 用户手册

本文档面向日常使用者，按任务路径说明如何完成行为树编辑、调试与回放。

## 1. 快速开始

1. 安装依赖：`npm install`
2. 启动前端：`npm run dev`
3. 浏览器访问：`http://localhost:5173`
4. 打开后默认进入“编排模式”。

## 2. 三种工作模式

| 模式 | 适用阶段 | 主要能力 |
|---|---|---|
| 编排模式 | 设计与修改树结构 | 拖拽节点、连线、属性配置、XML 导入导出 |
| 调试模式 | 在线执行观察 | 连接调试会话、断点、状态与黑板监控 |
| 回放模式 | 离线复盘分析 | 时间轴播放、事件筛选、书签定位 |

## 3. 常用任务

### 3.1 新建并编辑行为树（编排模式）

1. 从左侧节点库拖拽节点到画布。
2. 拖拽节点端口建立连接。
3. 选中节点后，在右侧属性面板配置参数和端口。
4. 使用顶部工具栏导入/导出 XML。

### 3.2 连接调试会话（调试模式）

1. 切换到“调试模式”。
2. 在顶部“连接”菜单中配置目标地址并连接。
3. 连接成功后观察节点状态高亮与事件流。
4. 在节点或断点面板中维护断点。

### 3.3 回放执行过程（回放模式）

1. 切换到“回放模式”。
2. 加载录制数据或离线日志。
3. 使用时间轴控制播放、暂停、跳转。
4. 使用筛选器查看特定事件与变量变化。

## 4. 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+S` | 保存当前行为树 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| `Delete` | 删除选中节点或连线 |
| `Ctrl+A` | 全选节点 |
| `Ctrl+F` | 搜索 |
| `F7` | 调试模式单步执行 |
| `F9` | 切换断点 |

## 5. 常见问题

### 5.1 连接不上调试后端

- 确认代理服务已启动。
- 检查 WebSocket 地址和端口。
- 检查后端日志中是否有协议错误。

### 5.2 XML 导入失败

- 确认 XML 符合 BehaviorTree.CPP 结构。
- 检查是否引用了未注册的自定义节点。

### 5.3 回放卡顿

- 缩小时间窗口。
- 关闭不必要轨道。
- 减少同时展示的变量数量。
