# BT Web Studio 概要设计

本文档是开发者入口，负责说明文档分层、核心架构边界与代码映射关系。

## 1. 目标与范围

- 目标：建立“可维护、可检索、可追踪”的文档体系。
- 范围：架构层、模式层、共享组件层、协议层、模块层。
- 非目标：替代代码注释；实现细节以 `src/` 为准。

- 代码结构变化时，同步更新“模块层”文档。
- 模式行为变化时，同步更新“模式层”和“组件层”文档。
- 协议字段变化时，必须同步更新“协议层”全部相关文档。
