# 属性面板

## 1. 目标与范围

- 目标：统一节点属性查看与编辑体验。
- 范围：节点信息、端口配置、参数绑定、高级设置、模式特化。
- 非目标：调试协议通信实现。

## 2. 依赖与入口

- 编排面板：`src/components/layout/composer-property-panel.tsx`
- 通用属性面板：`src/components/layout/properties-panel.tsx`
- 端口配置：`src/components/layout/ports-config-panel.tsx`
- 模型驱动配置：`src/components/layout/model-driven-config-panel.tsx`

## 3. 核心概念

- 基本信息：节点类型、实例名、分类。
- 端口配置：输入/输出端口定义、方向、默认值。
- 参数绑定：字面量值与黑板键绑定。
- 模式差异：编排可编辑，调试/回放以展示为主。

## 4. 关键流程

1. 画布选中节点。
2. 面板加载节点模型与当前属性。
3. 用户修改端口或参数。
4. 执行本地校验并写回 store。

## 5. 异常与边界

- Root 节点限制：唯一、连接约束、端口约束。
- 模型固定端口不可删除。
- 非法输入必须即时提示，避免写入无效状态。
