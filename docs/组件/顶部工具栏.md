# 顶部工具栏

## 1. 目标与范围

- 目标：提供三模式统一入口和模式特化操作。
- 范围：模式切换、文件/连接/加载入口、预览、设置、帮助。
- 非目标：具体业务弹窗实现细节。

## 2. 依赖与入口

- 组件实现：`src/components/layout/top-bar.tsx`
- 模式状态：`src/core/store/workflowModeState.ts`
- 菜单入口补充：`src/components/layout/function-tabs.tsx`

## 3. 核心规则

| 模式 | 显示项 |
|---|---|
| 编排 `composer` | 文件、预览、设置、帮助 |
| 调试 `debug` | 连接、预览、设置、帮助 |
| 回放 `replay` | 加载、预览、设置、帮助 |

始终显示：模式切换器、预览、设置、帮助。

## 4. 关键流程

1. 用户切换模式。
2. 工具栏根据 `currentMode` 切换功能区。
3. 功能区触发对应 action（导入、连接、加载等）。
4. 结果通过 Toast 或面板反馈。

## 5. 异常与边界

- 模式切换中不重复触发按钮动作。
- 连接类动作失败时必须可重试。
- 移动端保留关键操作，次要项可折叠。
