# 编排模式

## 1. 目标与范围

- 目标：提供结构化、可校验的行为树编辑体验。
- 范围：节点拖拽、连线、属性编辑、XML 导入导出、基础校验。
- 非目标：实时执行控制和回放分析。

## 2. 依赖与入口

- 布局容器：`src/components/layout/composer-layout.tsx`
- 画布：`src/components/layout/composer-canvas.tsx`
- 节点库：`src/components/layout/node-library-panel.tsx`
- 属性面板：`src/components/layout/composer-property-panel.tsx`
- 状态：`src/core/store/composerModeState.ts`、`src/core/store/treeState.ts`
- XML：`src/core/bt/xml-utils.ts`、`src/core/bt/global-xml-processor.ts`

## 3. 核心概念

- 结构对象：`nodes` + `edges`。
- 节点类型：`Action`、`Condition`、`Control`、`Decorator`、`SubTree`。
- 编辑约束：
  - Root 节点唯一。
  - 禁止非法连线与结构环。
  - 端口配置需要保持唯一与方向一致。

## 4. 关键流程

1. 从节点库拖拽节点到画布。
2. 在画布连线形成树结构。
3. 在属性面板配置端口和参数。
4. 执行结构校验并提示问题。
5. 导出 XML 或导入已有 XML 继续编辑。

## 5. 异常与边界

- 导入 XML 失败时，仅更新错误提示，不覆盖现有编辑状态。
- 删除节点时需要清理关联边与选择状态。
- 大规模节点编辑应避免每次操作全量重排布局。
