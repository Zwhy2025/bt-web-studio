# 回放模式

## 1. 目标与范围

- 目标：基于已记录事件进行时序回放与问题复盘。
- 范围：时间轴控制、轨道筛选、节点状态回放、书签定位。
- 非目标：修改树结构或发起调试控制命令。

## 2. 依赖与入口

- 布局容器：`src/components/layout/replay-layout.tsx`
- 画布：`src/components/layout/replay-canvas.tsx`
- 时间轴：`src/components/layout/timeline-controller.tsx`、`bottom-timeline.tsx`
- 状态：`src/core/store/replayModeState.ts`、`timelineState.ts`

## 3. 核心概念

- 回放会话：事件集合 + 时间范围。
- 时间轴：轨道化事件呈现，支持播放/暂停/跳转。
- 轨道类型：状态轨、日志轨、断点轨、黑板轨。
- 书签：对关键时刻进行定位和快速回看。

## 4. 关键流程

1. 载入录制数据（调试录制或离线文件）。
2. 初始化时间轴窗口和事件筛选条件。
3. 播放推进当前时间点并驱动画布状态。
4. 通过书签、筛选、节点定位复盘问题。

## 5. 异常与边界

- 空事件集时显示占位与导入引导。
- 非法事件时间戳需在加载阶段校验并过滤。
- 大体量事件需启用虚拟化与采样显示。
