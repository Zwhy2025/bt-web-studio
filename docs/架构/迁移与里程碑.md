# 迁移与里程碑

## 1. 目标与范围

- 目标：以低风险方式推进三模式架构与文档体系重构。
- 范围：文档迁移、结构拆分、链接修复、验收标准。

## 2. 当前状态

- 已完成：`docs/` 分目录重构，拆分协议与工作流大文档。
- 进行中：补齐模块文档与引用校验。
- 待推进：结合实现进度持续更新模式细节。

## 3. 里程碑定义

### M1 文档骨架迁移

- 建立 `架构/模式/组件/协议/模块/研发`。
- 完成入口文档：`docs/README.md`、`概要设计.md`。

### M2 协议拆分

- 将 Groot2 协议拆成总览、命令、事件、错误、示例五份。
- 协议字段与代码映射写入文档。

### M3 模块文档补齐

- 新增 `core-bt/core-store/core-debugger/core-layout/components-layout/hooks`。
- 明确每个模块的输入输出与边界。

### M4 链接与发布校验

- 修复 README、UI 菜单和文档内部引用。
- 完成一次构建与链接巡检。

## 4. 验收标准

- 不存在孤立文档或失效链接。
- 原超大文档已拆分并可定位到对应子文档。
- `用户手册.md` 与前端入口保持可访问。
- 新增模块文档均包含“目标、入口、流程、边界”四个核心部分。

## 5. 风险与应对

- 风险：实现代码快速变化导致文档过期。
- 应对：以模块文档为最小更新单位，在 PR 中强制同步。

- 数据流：`状态管理与数据流.md`
